# Skills Registry

MyWorldProject Classroom에서 사용하는 스킬 카탈로그입니다.

## Type A — 실행 스킬 (`.cursor/skills/`)

| Skill | 용도 |
|---|---|
| `github-workspace` | 프로덕트 레포·워크스페이스·registry 등록 |
| `product-planning` | PRD·로드맵·MVP 범위 정의 |
| `security-audit` | Secret·환경변수·기본 보안 점검 |
| `deploy-pipeline` | 학생 프로덕트 배포 전략 수립 |

## Type B — 팀 맥락 스킬 (`organization/`)

13팀 조직 구조와 역할을 기반으로 Agent가 작업 맥락을 구성합니다.

| 그룹 | 팀 |
|---|---|
| 제품/서비스 | 프로덕트, 디자인, QA |
| 기술 | IT |
| 성장 | 마케팅, 광고영업, 사업개발, 데이터 |
| 운영 | 운영, 고객센터 |
| 경영지원 | 재무, 홍보/법무, HR |

## 원칙

- 프로덕트명·계정·로컬 절대경로를 스킬에 하드코딩하지 않는다.
- 실제 대상 프로젝트는 `workspace/context/product-registry.md`에서 확인한다.
