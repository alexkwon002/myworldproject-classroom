# Frontend / Web 트랙

## 범위

- 웹 UI 구조
- 컴포넌트 설계
- 접근성
- 반응형 레이아웃
- 성능·SEO 기본 점검

## Agent 요청 예시

```text
[Web] active_product_id 기준으로 첫 랜딩 페이지 IA와 컴포넌트 구조를 설계해줘.
```

## 원칙

- 실제 대상 프로젝트는 `workspace/context/product-registry.md`에서 확인한다.
- `.env.*` 실값 수정·노출은 사용자 확인 없이는 진행하지 않는다.
- HQ cwd가 아니라 대상 프로덕트 cwd에서 제품 명령을 실행한다.
